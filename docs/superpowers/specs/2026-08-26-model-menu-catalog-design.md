# 模型菜单复刻设计

用户已确认：移除模型菜单内的 API 密钥设置入口，复刻参考项目的分组、搜索、模型名称和两行说明，直接复用其 Logo 源码。

参考：`D:/chatvip.aittco.com/chatvip-ai-chat-main/components/ChatInterface.tsx` 的 ModelLogo 与菜单，以及 `components/GrokLogo.tsx` 和 `public/logo/claude-ai-icon.svg`。

## 范围与行为

- 顶部当前模型按钮和菜单行使用同一套品牌 Logo；不改变消息头像或首页欢迎布局。
- 主菜单宽 320px，搜索固定在顶部，列表最高 420px；受可用视口限制。
- 普通模型直接按 GEMINI、OPENAI、GROK、ANTHROPIC 分组展示。未知供应商和自定义 modelSpec 保留，不硬编码可用模型列表。
- 模型行显示 Logo、可读名称和两行说明；悬停可查看完整文本；选中项高亮并有勾选标记。保留收藏操作。
- 搜索覆盖模型 ID、显示名称、厂商别名和说明，隐藏无匹配分组。计数来自实际可选项。
- 保留现有 Agent/Assistant 的名称、头像、权限和专用菜单行为，避免破坏大型列表及商城入口。
- 保留原有选择处理函数和请求 ID。仅展示名称可读化，不修改模型 ID、请求参数或密钥。
- 删除模型菜单中的齿轮入口和该菜单挂载的密钥弹窗；首页密钥管理保持原状。
- 支持方向键、Enter、Escape、点击外部关闭及移动端点击。
- 复用已有 Ariakit 菜单与语义主题色。SVG 品牌颜色属于素材，其他样式随主题变化。
- 中文和英文说明集中管理；未知型号不编造性能、价格或能力排名。

## 验收

真实菜单测试覆盖分组、搜索、选择、关闭、密钥入口缺失、未知模型、重复模型跨端点以及 modelSpec。运行相关原有测试和 TypeScript/ESLint。使用浏览器验证浅色、深色、窄屏与滚动，记录是否使用了模拟 API 数据。
