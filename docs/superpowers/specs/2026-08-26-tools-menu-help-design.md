# 工具菜单悬浮说明与隐藏网络搜索设计

## 目标

让聊天输入框工具菜单中的功能对新用户可理解、可操作：鼠标悬浮时显示“这是什么、有什么用、如何使用”的轻量提示卡；从菜单中隐藏当前不使用的网络搜索入口。

## 范围

涉及 `client/src/components/Chat/Input/ToolsDropdown.tsx` 及其本地化文案和测试。保留网络搜索后端能力、权限判断和配置代码，仅移除聊天工具菜单中的渲染入口，避免影响其他功能。

## 交互设计

每个工具菜单项使用统一的悬浮提示卡。悬浮约 300ms 后显示，卡片定位在菜单右侧；鼠标移动到卡片时保持显示，离开后关闭。菜单项保留现有点击开关、固定/取消固定和配置按钮行为。提示卡同时通过键盘焦点可访问；窄屏或触摸设备使用点击/长按触发同一说明。

提示卡统一分为三段：

- **这是什么**：用一句话解释功能。
- **有什么用**：说明典型价值和适用场景。
- **如何使用**：给出具体步骤和一个可复制的示例。

### 文件搜索

说明用户点击回形针上传文件，等待处理后直接提问；示例为“找出合同中的付款条款”。

### Skills

Skills 是可复用的专业工作流程。说明开启 Skills 后，在输入框输入 `$` 查看列表，选择或输入技能名调用，再描述任务；示例 `$thesis-outline` 加论文提纲请求。说明支持在 Skills 管理中上传包含 `SKILL.md` 的本地 Skill 文件夹，上传后通过 `$` 列表调用；若未出现，重新打开菜单或刷新列表。

### 记忆

说明开启后可在对话中告诉 AI 需要长期记住的信息，例如“以后都用中文回答，称呼我为小李”。

### 运行代码

说明开启后可要求 AI 计算、处理数据或绘图；示例为分析 CSV 并绘制销售趋势图。

### Artifacts

说明开启后可要求生成可在独立预览区查看、修改、运行或下载的代码、网页、图表或文档；示例为生成可交互销售看板。

### 网络搜索

不再加入 `ToolsDropdown` 的 `dropdownItems`。其他网络搜索能力不在本次范围内改动。

## 文案与本地化

新增工具说明文案集中放在英文和简体中文翻译资源中，组件只引用本地化 key。中文是本次主要使用语言，英文提供默认回退。文案使用短段落和标题，避免一整段难以扫描的文本。

## 技术实现

- 在 `ToolsDropdown` 中定义工具说明映射，或抽取为独立的 `ToolInfoTooltip` 组件。
- 复用现有 `TooltipAnchor`/Popover 基础设施，避免引入新的浮层依赖。
- 确保说明触发器和菜单交互事件隔离，点击固定按钮、设置按钮时不触发工具开关。
- 移除网络搜索菜单项后，相关搜索状态、设置弹窗引用和权限逻辑若仅用于该项则一并清理，避免无效变量；若被其他上下文使用则保留。

## 验证

增加或扩展 `ToolsDropdown` 测试，覆盖：

1. 网络搜索菜单项不渲染。
2. 文件搜索、Skills、记忆、运行代码和 Artifacts 的说明可通过悬浮/焦点触发器访问。
3. Skills 说明包含 `$` 调用和本地 `SKILL.md` 上传指引。
4. 原有开关、固定和设置按钮行为未被破坏。

运行相关单元测试和客户端类型检查/构建，确认没有 TypeScript 或 lint 回归。
